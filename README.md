# Connect

Local copies of things saved elsewhere, with room to add our own tools on top.

The official Raindrop apps stay installed and keep syncing with raindrop.io. This repo holds the changes we make ourselves.

| Path | What it is |
| --- | --- |
| `raindrop-bookmark-app/library` | Our bookmark web app. Seeded from a Raindrop HTML export, updated from the API when asked. |
| `raindrop-bookmark-app/raindrop-chrome-extension` | Raindrop's extension source (MIT, upstream `raindropio/app`) plus an Invisible save setting. See `UPSTREAM.txt`. |
| `raindrop-bookmark-app/raindrop-manual-exports` | HTML exports. Not committed: the GitHub repo is public. |

`raindrop-desktop-app` and `raindrop-api` are local checkouts of the upstream desktop client and API docs. They are not part of this repo.
