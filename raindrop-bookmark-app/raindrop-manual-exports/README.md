# Raindrop HTML export

This folder holds bookmark files exported from Raindrop by hand. There is no program to start here.

The file used by the library is `raindrop-bookmark-export-26Sep26.html`, exported on 26 Sep 2026. It is not in git, because the Connect repo on GitHub is public. The library in `../raindrop-website-app` reads it when `../raindrop-website-app-data/bookmarks.sqlite` is missing.

## See the export

### Go to this folder

```sh
cd /Users/john/dev/connect/raindrop-bookmark-app/raindrop-manual-exports
```

### List the files

```sh
ls -lh
```
